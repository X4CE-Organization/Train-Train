# Train Train / 混乱火车 — Design Notes

© 2026 X4CE

## 一句话玩法

列车可以随手启停，但车站会不断产生乘客。玩家要改变列车抵达的下一条线路，并在有限时间内持续完成上下客。

## 核心循环

1. 关卡开始时列车自动发车，车厢初始为空，单个车厢最多容纳 6 名乘客。
2. 点击车身可以随时停车或恢复行驶；列车到达岔口时读取当前道岔方向。
3. 玩家点击白色箭头循环切换出口，并利用侧线与停车调度交叉车流。
4. 列车经过车站会自动停靠：同色乘客下车，然后装载站台上数量最多的颜色。
5. 累计送达本关目标人数后结算时间星级并解锁下一关。
6. 任意两列车相撞会立即结束本关，倒计时归零同样失败。

## 模式与车库

- **关卡模式**：按世界区域推进 48 关，按剩余时间评定 1–3 星。
- **无尽模式**：从当前进度开始，每完成 30 名乘客进入下一阶段并补充 20 秒。
- **列车车库**：四种车型随累计星星解锁，容量与速度不同，选择结果会持久保存。
- **关卡编辑器**：使用网格拖拽铺轨、放置地面轨/高架轨/隧道/侧线/车站/列车，校验并试玩，自定义关卡保存为本地 JSON。高架首尾自动生成坡道，禁止和地面轨直接共点连接。

## 设计支点

- **手控启停**：列车可以随时停车，节奏完全由玩家掌握。
- **短时预测**：玩家必须提前判断下一条线路，而不是看到结果后补救。
- **交叉让行**：无自动信号的路口要求玩家主动制造时间差。
- **侧线待避**：列车可以停进支道，让出主线后再恢复行驶。
- **时间星级**：完成越快星级越高，鼓励重复优化路线。
- **颜色语言**：四种高对比色彩同时承担列车涂装、站点、乘客和得分反馈。
- **列车差异**：流线快车速度更高但容量较低，其余车型分别偏向均衡、容量和重载。

## 区域结构

| 区域 | 地图结构 | 视觉语言 |
| --- | --- | --- |
| 松岭 | 矩形环路 + 中央连接线 | 松树、薄雾、木色轨道 |
| 赤岩 | 剪刀式斜向循环 | 岩柱、暖色峡谷、铁路小屋 |
| 霜原 | 双层横向线路 + 中央交汇 | 雪松、冷灰地面、亮橙信号 |
| 霓虹港 | 三横线 + 菱形交叉 | 深蓝夜色、霓虹灯、集装箱 |
| 沙海 | 稀疏环形与长距离支线 | 沙丘、仙人掌、暖金色 |
| 云港 | 收束式高层路网 | 云团、青绿色地形、空中站台 |
| 金穗谷 | 方格环线与对角捷径 | 麦田、草垛、暖色谷仓 |
| 雾都 | 多层收束和连续咽喉 | 雾树、路灯、深色砖石 |

八个区域分别包含 4、5、5、6、6、7、7、8 关，共 48 关。每关从主题路网抽取一棵连通主干，只保留零到两条有意义的环线，再旋转或翻转布局。难度提升主要来自列车数、道岔压力、乘客目标和发车节奏，而不是继续堆叠装饰线路。

## 技术取向

- Unity 2022.3 LTS，Built-in Render Pipeline。
- 场景、低多边形模型、轨道、云、树、列车和音效均在运行时生成。
- 界面使用 IMGUI 固定虚拟坐标缩放，并使用系统动态字体覆盖中文。
- 所有持久化使用 `PlayerPrefs`，键名前缀为 `TrainTrain_ChaosRail_v2_`，并保留旧前缀的迁移逻辑。
- 地图和铁路使用整数网格，运行节点图与渲染完全解耦，便于继续添加关卡。
